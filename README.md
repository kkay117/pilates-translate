# 필라번역 — 실시간 필라테스/PT 통역기 (완전 무료)

강사님이 한국어로 말하면 실시간으로 인식해서, 필라테스·물리치료 전문용어를
반영한 번역을 화면 자막 + 음성(TTS)으로 보여주는 웹앱입니다.
**API 키 발급이나 결제 없이 바로 사용할 수 있습니다.**

## 동작 방식

1. 브라우저 내장 음성인식(Web Speech API)이 한국어 음성을 텍스트로 변환 (무료)
2. 문장 안의 필라테스/PT 전문용어(코어, 골반저근, 리포머, 롤업 등)를
   `glossary.js`의 사전과 대조해 영어 힌트를 붙임 → 번역 정확도 향상
3. [MyMemory Translation API](https://mymemory.translated.net) (무료, 키 불필요)로
   선택한 언어로 번역
4. 화면에 자막으로 표시하고, 선택 시 음성으로도 읽어줌 (브라우저 내장 TTS, 무료)

## 1. 앱 실행하기

준비물 없음 — API 키 발급, 가입, 결제 전부 필요 없습니다.
Chrome 또는 Edge 브라우저를 권장합니다 (음성 인식은 Chromium 기반 브라우저만 지원).

**옵션 A — 그냥 열기**

`index.html` 파일을 더블클릭해서 Chrome으로 엽니다. 대부분의 경우 바로 동작합니다.

**옵션 B — 로컬 서버로 실행 (마이크 권한이 안 될 때 권장)**

이 폴더에 `_serve.ps1`이라는 간단한 로컬 서버 스크립트가 포함되어 있습니다
(Python 등 별도 설치 불필요, Windows 기본 PowerShell만 있으면 됨).

```powershell
powershell -ExecutionPolicy Bypass -File _serve.ps1 -Port 8791
```

실행 후 브라우저에서 `http://localhost:8791` 접속.
(Python이 설치되어 있다면 `python -m http.server 8791` 로도 실행 가능합니다.)

## 2. 모바일(폰)에서 쓰기

수업 중 폰을 들고 쓰는 상황에 맞춰 만들어졌습니다.

**Android (Chrome 권장)**

1. PC와 폰을 **같은 Wi-Fi**에 연결
2. 위 1번 방법대로 PC에서 `_serve.ps1`을 실행
3. PC의 로컬 IP 확인: PowerShell에서 `ipconfig` 실행 후 "IPv4 주소"
   (예: `192.168.0.15`) 확인
4. 폰 Chrome에서 `http://192.168.0.15:8791` 접속 (숫자는 본인 PC 주소로 교체)
   - 처음 접속 시 Windows 방화벽이 "차단"으로 되어 있으면 접속이 안 될 수
     있습니다. 방화벽 알림이 뜨면 **허용**을 눌러주세요
5. Chrome 메뉴(⋮) → **홈 화면에 추가** → 앱처럼 아이콘으로 실행 가능
6. 🎤 버튼으로 듣기 시작하면 자동으로 화면이 꺼지지 않도록 잠금이 걸립니다
   (수업 중 화면이 잠들어 인식이 끊기는 것을 방지, Wake Lock 지원 브라우저 한정)

**iPhone (Safari)**

- iOS Safari는 Web Speech API(실시간 음성 인식)를 지원하지 않아 마이크 기능이
  동작하지 않습니다. 아이폰에서는 Chrome도 내부적으로 Safari 엔진을 쓰므로
  동일하게 제한됩니다. **음성 인식(마이크) 기능은 Android 폰 또는 PC의
  Chrome/Edge에서만 사용 가능합니다.**
- 아이폰에서는 마이크 버튼이 자동으로 비활성화되고, 대신 화면 하단의
  **텍스트 입력창**에 한국어 문장을 직접 타이핑하면 번역 + 음성 출력이 동일하게
  동작합니다. 자주 쓰는 큐잉 문장은 미리 타이핑해두고 써도 좋습니다.
- 이 텍스트 입력창은 Android/PC에서도 항상 사용 가능합니다 (조용한 곳에서
  음성 대신 타이핑하고 싶을 때 등).

화면은 폰 화면 크기에 맞춰 자동으로 조정되며(반응형), 버튼과 입력창은 터치하기
쉬운 크기로 만들어져 있습니다.

## 3. 사용 방법

1. 상단에서 외국어 선택 (영어/일본어/중국어/베트남어 등)
2. **⇄ 방향 전환** 버튼으로 번역 방향을 바꿀 수 있습니다
   - "한국어→영어": 강사님이 한국어로 말하면 → 외국어로 번역 (기본값)
   - "영어→한국어": 회원이 외국어로 말하면 → 한국어로 번역 (회원이 답하거나
     질문할 때 사용)
3. 🎤 마이크 버튼을 눌러 듣기 시작 (브라우저가 마이크 권한을 요청하면 허용).
   방향을 바꾸면 음성 인식 언어도 자동으로 함께 바뀝니다 (예: 영어→한국어
   방향에서는 영어를 알아듣도록 전환됨)
4. 말을 하면 문장이 끝날 때마다 자동으로 번역되어 자막으로 표시되고,
   "음성 출력"이 켜져 있으면 소리로도 읽어줍니다
5. 다시 마이크 버튼을 누르면 듣기 중지
6. 하단 "지난 번역"에서 방금 지나간 문장들을 다시 확인 가능

전문용어 힌트(용어 사전)는 한국어→외국어 방향에서만 적용됩니다. 회원이
외국어로 말할 때(반대 방향)는 일반 번역만 적용되며, 원어민이 아닌 이상 짧고
간단한 문장일 때 번역 품질이 가장 좋습니다.

### (선택) 무료 사용량 한도 늘리기

MyMemory는 익명으로 하루 약 5,000단어까지 무료로 번역할 수 있습니다.
⚙️ 설정에서 이메일을 입력하면 한도가 하루 약 10,000단어까지 늘어납니다
(회원가입이 아니라 단순히 사용량 한도를 위한 식별용이며, 별도 인증 메일이
오지 않습니다). 수업 시간이 길다면 입력을 권장합니다.

## 4. 전문용어 사전 관리

`glossary.js`에 약 60개의 필라테스/PT 기본 용어가 들어있습니다
(코어, 골반저근, 척추 중립, 리포머, 롤업, 헌드레드 등).

설정 화면에서 새 용어를 직접 추가할 수도 있습니다 (예: "임프린트" → "imprint").
추가한 용어는 브라우저에 저장되어 계속 유지됩니다.

번역 시 이 용어들 뒤에 영어 힌트가 자동으로 삽입되어 번역기가 더 정확한
전문용어 번역을 하도록 유도합니다. 이 기능이 마음에 안 들면 설정에서
"전문용어 힌트 사용"을 꺼도 됩니다 (일반 번역만 사용).

## 참고 / 제한사항

- 음성 인식은 인터넷 연결이 필요합니다 (Google 서버로 오디오 전송)
- 소음이 많은 스튜디오에서는 인식 정확도가 떨어질 수 있습니다.
  마이크와 입 사이 거리를 가깝게 유지하는 걸 권장합니다
- Safari, Firefox는 Web Speech API 지원이 불완전하여 Chrome/Edge 사용을 권장합니다
- 각 언어의 TTS 음성은 운영체제/브라우저에 설치된 음성 목록에 따라 달라집니다
- MyMemory는 무료 서비스라 Google/DeepL 등 유료 엔진보다 번역 품질이 다소
  낮을 수 있습니다. 특히 긴 문장보다는 수업 중 짧은 지시문(큐잉) 번역에 적합합니다
- 하루 무료 사용량(약 5,000~10,000단어)을 초과하면 일시적으로 번역이 안 될 수
  있으며, 다음 날 자동으로 초기화됩니다
